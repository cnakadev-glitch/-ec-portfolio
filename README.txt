ひとくち商店 — サイトファイル一式

【内容】
index.html：ページの構造と文章
style.css：デザイン・スマートフォン向け表示
app.js：商品情報・検索・カテゴリ・カート・デモ購入
snacks.jpg：掲載画像

【開き方】
ZIPを展開し、パソコンのブラウザでindex.htmlを開いてください。
4ファイルは同じフォルダに置いてください。

【公開する場合】
4ファイルを公開先の同じ公開用フォルダへアップロードします。
公開先のURLで表示・動作を確認してください。

【編集】
文章・構造はindex.html、見た目はstyle.css、商品名・価格・動作はapp.jsを編集します。

【注意】
自主制作の購入体験デモです。実際の注文・決済は発生しません。
商品を編集する管理画面はありません。
